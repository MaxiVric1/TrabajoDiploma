Cómo instalar SQL Server para LandSmart

LandSmart guarda sus datos en Microsoft SQL Server. Si el instalador no encontró ninguno en esta PC, siga estos pasos y vuelva a ejecutarlo.

¿Qué versión elegir?

SituaciónOpción recomendada
Una sola PC y un solo usuario de Windows No hace falta descargar nada: en el instalador de LandSmart elija Instalar SQL Server Express LocalDB.
Varios usuarios de Windows en la misma PC, o varias PC SQL Server Express (gratuito), siguiendo los pasos de esta guía.
La empresa ya tiene un servidor SQL Server No instale nada: en el instalador elija Otro servidor y escriba su nombre (por ejemplo SERVIDOR\SQLEXPRESS).
1

Descargar SQL Server Express

  1. Abra la página de descargas de Microsoft.
  2. En la sección Express, haga clic en Descargar ahora.
  3. Se descarga un instalador pequeño (por ejemplo SQL2022-SSEI-Expr.exe).
Abrir la página de descarga
2

Instalar con la opción «Básica»

  1. Ejecute el archivo descargado y acepte el permiso de administrador de Windows.
  2. Elija el tipo de instalación Básica (Basic).
  3. Acepte los términos de la licencia y deje la carpeta de instalación propuesta.
  4. Haga clic en Instalar y espere a que termine (descarga varios cientos de MB; puede tardar varios minutos).
  5. Al final, la pantalla muestra el nombre de la instancia: SQLEXPRESS. Cierre el instalador; no hace falta instalar SSMS ni ninguna otra herramienta.

La instalación Básica deja como administrador de SQL Server a la cuenta de Windows que la ejecutó.

3

Volver a ejecutar el instalador de LandSmart

  1. Ejecute de nuevo LandSmart-Setup con la misma cuenta de Windows que instaló SQL Server.
  2. En la página Base de datos aparecerá .\SQLEXPRESS marcada como [disponible]. Selecciónela y haga clic en Siguiente.
  3. El instalador crea la base de datos, da acceso a los usuarios de la PC y verifica que todo funcione.

Si algo no funciona

  • «El servicio no está iniciado»: el instalador intenta iniciarlo solo. Si no puede, abra services.msc, busque SQL Server (SQLEXPRESS) y elija Iniciar.
  • «No es administradora (sysadmin) de SQL Server»: ejecute el instalador de LandSmart con la cuenta de Windows que instaló SQL Server, o pida a quien administra el servidor que le dé ese permiso.
  • Servidor en otra PC: en ese servidor tienen que estar habilitados TCP/IP (en SQL Server Configuration Manager) y el acceso por el firewall de Windows.
  • Si la instalación de LandSmart falla, no se instala nada y queda el detalle en Documentos\LandSmart_instalacion_fallida.log.
